# FEA Coach Native v2

Nowa natywna aplikacja Android budowana na kompletnej, zweryfikowanej bazie FEA Coach System.

## Stan etapu 7

- 40 środków FEA,
- 40 środków motorycznych,
- 26 zachowań problemowych,
- 80 przypisanych grafik,
- dane dostępne offline,
- kontrola integralności bazy przy uruchomieniu.
- natywny ekran główny,
- formularz analizy meczu,
- automatyczne rozpoznanie zachowania z możliwością ręcznej korekty,
- diagnoza i plan poniedziałkowy,
- pięć kart treningowych z grafiką i pełnym opisem środka.
- trwały zapis mikrocyklu w pamięci telefonu,
- ekran Poniedziałek / Środa / Piątek,
- Training Score R/W/P/G oraz ocena każdego środka,
- automatyczne utworzenie środy po ocenie poniedziałku,
- automatyczne utworzenie piątku po ocenie środy,
- historia wyników Training Score.
- biblioteka 40 FEA i 40 środków motorycznych,
- wyszukiwanie po całej treści kart,
- podgląd oryginalnej grafiki i opisu,
- ręczna podmiana środka w planie,
- zapis powodu i historii każdej podmiany.
- konspekt PDF: maksymalnie 2 strony A4 poziomo,
- grafika po lewej i pełny opis po prawej,
- osobny dokument Training Score PDF,
- osobny dokument KPI PDF,
- historia ocen i ręcznych decyzji,
- ekran startowy FEA Coach.

Oryginalne opisy środków nie są automatycznie modyfikowane.

## Budowa APK przez GitHub

1. Wgraj całą zawartość tej paczki do osobnego repozytorium GitHub.
2. Otwórz zakładkę **Actions** i workflow **Build FEA Coach Native APK**.
3. Po zielonym zakończeniu pobierz artefakt **FEA-Coach-Native-v2**.

Plik instalacyjny wewnątrz artefaktu nazywa się `app-debug.apk`.
